As you work through Genki it can be easy to forget grammar an vocabulary you learned lessons ago if you don’t use them often. Also, each time you get into a new lesson it can be hard to get acquainted with all the new grammar patterns and vocabulary. If you are already using an [SRS](https://en.wikipedia.org/wiki/Spaced_repetition#Software) software such as [Anki](https://apps.ankiweb.net/), then you are in luck! If not, then you should give it a try! It can make language learning easier and more efficient.

There is an deck for Anki called **Genki Anhliation which includes example sentences, divided by Genki lessons, along with audio spoken by a native speaker, English translations and brief vocabulary and grammar refreshers**. To make it even better it includes the sentences with kanji and [furigana](https://en.wikipedia.org/wiki/Furigana), so you can start getting acquitned with some kanji along the way.

## How do I get started with the Genki Annihilation Deck?

You may dowload it from this blog post, titled [An efficient Anki setup for learning Japanese](http://roessland.com/blog/2014/06/08/an_efficient_anki_setup_for_learning_japanese.html) which along Genki Annhilitation, it points you to other good Anki resources for Japanese.

## How do I use this deck?

Here are some tips from my own experience working through this deck.

- Make use of the deck’s tags. You can crete a separate deck and move cards from the lessons you have covered or you will cover soon into the new deck. That way you won’t get new cards for lessons you still haven’t covered and you will be able to review everything you have already worked through.
- Start working through the next lessons’ cards before you start studying the next lesson. At first some things might not make much sense, but once you get to that lesson everything will fall into place quicker that it would have if everything was new for you all of a sudden.
- Practice each card until you can read the sentence as fast as the native speaker. This will payoff greatly during conversation.
- Use the furigana only when necessary, try to start remebering how to read the kanji. Even if you don’t know those kanji yet, they will start sticking to you surprisingly fast.
- Read the lessons’ dialogues. Many of the example sentences come from these dialogues. The sentences will make sense after you see the whole context.
